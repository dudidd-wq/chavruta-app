# Fonts from chitas-reader (SIL Open Font License)

Self-hosted OFL families copied from dudidd-wq/chitas-reader, with original font names unchanged.

Included:
- Noto Serif Hebrew — default reading text
- Frank Ruhl Libre (variable 300–900) — headings and a text option
- Ezra SIL — vocalization and te'amim
- David Libre — text option, no te'amim
- Cardo — text option, includes te'amim
- Assistant (variable 200–800) — optional UI / reading sans
- Noto Rashi Hebrew — Rashi-script blocks

Each family is accompanied by its OFL license file. Do not rename the fonts.

Not included, on purpose:
- Taamey D, Taamey Ashkenaz, and Keter YG (GPL-2.0)
- SBL Hebrew (proprietary EULA; not licensed for a new public site)
