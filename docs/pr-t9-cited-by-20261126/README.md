# הצעת עיצוב: מאמרים שמפנים לכאן

לא למזג. לפי הערת דודי: גרף ההפניות הוא דו־כיווני. כל הפניה א→ב יוצרת גם «מפנה לכאן» בצד ב, גם אם לב אין הערות.

הנתונים כרגע מלקוטי שיחות (12,072 קישורי ft-cite): 4,513 יעדים מקבלים הפניה חוזרת, מהם 1,886 בלי הערות משלהם (למשל תורה אור ולקוטי תורה, שבהם אין הערות ארוזות בטיפוגרפיה).
